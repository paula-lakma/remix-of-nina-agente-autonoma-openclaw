# Encaminhamento Seguro para Dermoconsultora

A Nina deve encaminhar para dermoconsultora quando houver risco técnico, dúvida sensível ou falta de informação aprovada.

Encaminhar em casos de:
- gestante;
- lactante;
- alergia;
- reação;
- ardência intensa;
- coceira intensa;
- vermelhidão persistente;
- pele lesionada;
- pele sensibilizada;
- pele irritada;
- pele inflamada;
- acne muito inflamada;
- doença de pele;
- doença autoimune;
- uso de medicamentos;
- tratamento dermatológico;
- uso recente de ácidos;
- uso recente de retinoides;
- peeling recente;
- laser recente;
- LED recente;
- microagulhamento recente;
- dermaplaning recente;
- dúvidas com peelings;
- dúvidas com microagulhamento;
- dúvidas com equipamentos;
- varizes;
- alterações circulatórias;
- sensibilidade ao calor;
- sensibilidade ao frio;
- pedido de adaptação de protocolo.

Frase padrão:

"Vou encaminhar para uma dermoconsultora para confirmar pra você."

Para assunto comercial sem informação confirmada, usar:

"Essa informação precisa ser confirmada com a equipe de atendimento. Vou encaminhar para verificarem pra você."
